## Contents

- `index.html` — portfolio website
- `Pradyun_Srivastava_Resume.pdf` — current résumé PDF opened by the résumé buttons
- `assets/althire-career-page.png` — career-page UI preview image used in the AltHire project section

- AltHire AI — combined website, career page, and email-based ATS work
- AlbertaSat ASCENT — Power Team leadership and electrical power-system work
- University coursework and skills

The AltHire work is presented as one combined entry with links to the live careers page and the public career-page/ATS repository: https://github.com/PradyunME/Career-Page-ATS-System

## Run locally

Open `index.html` in a browser. No build step or package install is required. Keep the résumé PDF and `assets` folder next to `index.html` as shown above so the relative links work.

## Publish

Upload the contents of this folder to a static host such as GitHub Pages, Netlify, or Cloudflare Pages. Preserve the relative paths so the résumé PDF and career-page image load correctly.
